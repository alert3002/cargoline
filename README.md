# CargoLine.Tj

Премиальное Flutter-приложение для карго-доставки из Китая (Pinduoduo, Taobao, 1688) в Таджикистан.

## Дизайн

- **Фон:** `#FFF9F9` — мягкий красновато-белый
- **Карточки:** `#FFFFFF`, скругление 16px, мягкие тени
- **Акценты:** красный `#D32F2F` + тёмно-синий `#0D253F` (бренд CargoLine.Tj)
- **Анимации:** плавные переходы экранов, Hero-логотип, ripple-эффекты

## Экраны

| Вкладка | Описание |
|---------|----------|
| **Главная** | Логотип, адрес склада в Китае (копирование), добавление трек-кода |
| **Заказы** | 6 статусов + поиск потерянного товара |
| **QR** | Центральная кнопка — сканер трек-кодов |
| **Сообщения** | Уведомления и чат поддержки |
| **Профиль** | Код клиента, калькулятор, запреты, контакты |

## Авторизация

1. Ввод номера `+992` (Tcell, Babilon-T, Megafon, ZET Mobile)
2. SMS-подтверждение (демо: любой 4-значный код)
3. Переключатель языка **RU / TJ** на всех экранах

## Запуск

```bash
cd cargo_line_tj
flutter pub get
flutter run
```
